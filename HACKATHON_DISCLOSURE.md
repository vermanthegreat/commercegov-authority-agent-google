# Hackathon disclosure

## Pre-existing

CommerceGov is a pre-existing governance control plane, including its governed
review, approval, command, worker, and verification infrastructure. It is
external to this repository and has not been modified by this hackathon work.

## New hackathon work

This repository is new hackathon work. It contains the Google ADK authority
agent, Gemini authority assessment, event adapter, Pub/Sub integration
boundary, Firestore checkpoints, Cloud Run packaging, and idempotent
asynchronous workflow. Later hackathon work may add human-authority/resume
integration with CommerceGov.

## Development tooling

AI coding assistants may be used during development, including OpenAI Codex and
Cursor. They are development tools, not runtime dependencies of this service.
